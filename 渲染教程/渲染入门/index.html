欢迎来到 Unity 渲染入门课

这是为零基础写的 Unity 渲染教程，面向 VRChat 世界开发。每章 5-10 分钟，跟着做就行。

你会学到什么

理解「显卡是怎么把 3D 场景画成 2D 画面的」，学会调材质、打光、选 Shader，并掌握 VRChat 中渲染性能的关键限制。学完你能：把一个灰扑扑的场景，变成有光照、有质感、不卡顿的漂亮世界。

课程目录

  • 第 1 篇：渲染是什么 — 一帧画面怎么画出来
  • 第 2 篇：光照与 PBR — 光源、反射、烘焙
  • 第 3 篇：材质与 Shader — 参数、贴图、混合模式
  • 第 4 篇：VRChat 渲染实践 — URP、性能与优化
  • 第 5 篇：动手做一颗发光水晶
  • 第 6 篇：速查表 & 常见问题

怎么开始

  1. 打开 Unity 2022.3（VRChat SDK3 工程），确认工程已加载
  2. 从第 1 篇开始，每篇「看完 → 在 Unity 里做一遍 → 自检打勾」
  3. 配图都在 教程资源/ 文件夹里，可以随时参考
本教程假设你已经会 Unity 的基本操作（创建物体、拖拽组件）。如果完全没碰过 Unity，建议先花 30 分钟做一遍官方的 Create with Code 入门。
