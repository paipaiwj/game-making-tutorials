欢迎来到 Unity UI 入门课

这是专门为零基础写的 Unity UI 教程，面向 VRChat 世界开发。每个章节 5-10 分钟，跟着做就行。

课程目录

  • 第 1 篇：UI 与 Canvas — 建立 UI 结构概念，认识 Canvas、EventSystem、RectTransform
  • 第 2 篇：第一个 Text — TextMeshPro、中文显示、富文本
  • 第 3 篇：Button 与点击事件 — Button 结构、OnClick、VRChat 注意事项
  • 第 4 篇：Image 与 Panel — Image 类型、九宫格、半透明面板
  • 第 5 篇：Slider / InputField / Toggle — 常用输入控件和事件
  • 第 6 篇：综合小项目 — 登录界面 + 面板切换
  • 第 7 篇：World Space Canvas — 把 UI 放进 VRC 3D 世界
  • 第 8 篇：VRC UI Shape + UdonSharp — 让 UI 真的能被玩家点击
  • 第 9 篇：Scroll View — 滚动列表
  • 第 10 篇：Layout Groups — 自动排列
  • 第 11 篇：嵌套 Canvas — 弹窗层级
  • 第 12 篇：VRC 实战菜单 — 综合角色菜单
  • 第 13 篇：速查表 — 控件、Canvas、常见错误

怎么开始

  1. 打开 Unity，确认工程已经加载
  2. 从第 1 篇开始，每篇都是「看完 → 在 Unity 里做一遍 → 自检打勾」
  3. VRChat 相关章节会结合 VRChat 离线手册中的官方说明，遇到不确定的组件参数可以去查 vrc离线手册
  4. 卡住了随时喊我，我陪你做

本教程的 VRChat 主线

阶段篇目学完后你会…
Unity UI 基础1-6会做 Text / Button / Image / Slider / InputField / Toggle，能搭一个普通 Unity 界面
VRC 世界 UI7-8会配置 World Space Canvas + VRC Ui Shape + UdonSharp，做出世界内可点击 UI
进阶排版9-11会做滚动列表、自动布局、弹窗层级
综合实战12-13能独立完成一个 VRChat 角色菜单，并会用速查表排错
